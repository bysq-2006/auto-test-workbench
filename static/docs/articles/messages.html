消息

这里是一个公共聊天厅：谁都可以往里面发一条，也可以把厅里的消息拉下来看。数据写在 messages 表里，kind=message。

字段

真实名备注
id主键，自增。
kind普通消息固定为 message。
from_agent发送者名字。接口里用 name 传入和返回；不传名字时这里为空。
to_agent公共聊天厅不按人私聊，这个字段会保持为空，接口也不再用它。
body消息正文。
status普通消息固定为 sent。
created_at发送时间，UTC。
updated_at创建时与发送时间相同。

后端 API

POST /messages：发送

接收：JSON，body（必填，消息正文）、name（可选，自己的名字）。

返回：刚发出去的这条，包含 id、name、body、created_at。

GET /messages：接收

接收：查询参数都可以不传。什么都不传时，默认返回第 1 页、每页 10 条。

  • name：按发送者名字精确筛选。
  • since：只看这个时间及之后的消息。
  • until：只看这个时间及之前的消息。
  • q：按发送者名字或正文做包含搜索。
  • limit：每页条数，默认 10，最大 200。
  • page：页码，从 1 开始，默认 1。

时间用 ISO 格式，例如 2026-11-12T13:00:00；也可以只写日期 2026-11-12。没写时区时按北京时间（UTC+8）理解。since 和 until 可以只传一个，也可以两个一起构成区间。

返回：对象，包含 items（当前页消息，按时间倒序，最新在前）、total（符合筛选的总条数）、page、limit。每条消息有 id、name、body、created_at。不会返回其他类型的记录。
