轮次

一轮就是一次测试委托：崇州一轮、德阳一轮、民政厅一轮。数据表 rounds。tasks、test_results、messages 各有一列 round_id 指过来，界面顶部按轮次切换。

技能和资源不分轮次。技能是 skills/ 目录现场扫出来的，资源是整台机器共用的浏览器池，两者都不挂 round_id，换轮次也不会变。

字段

真实名备注
id主键，自增。就是提示词里说的「本轮编号」。
name轮次名，例 崇州-26.11.18。最多 40 字，不能含 \ / : * ? " < > |，因为它要当目录名。
statusopen（进行中）或 closed（已归档）。关闭后只能看；关错了可以 reopen 启用回来。
note本轮结论。关闭时必须写一句。
dir本轮临时目录的绝对路径，创建时自动建好。
created_at创建时间，UTC。
closed_at关闭时间，UTC；没关时为空。

列表返回值还会带上 tasks、results、messages（各挂了多少条）和 alive_tasks（还没跑完的任务数）。

后端 API

GET /rounds：查看轮次

接收：无参数，按编号倒序，新的在前。

返回：{items, unassigned}。unassigned 是三张表里 round_id 为空（未归类）的条数，全为 0 时界面不显示「未归类」这一项。

POST /rounds：开一轮

接收：JSON，name（必填）、note（可选）。

返回：新建的轮次。同时会在 runs/ 下建好 <编号>-<名字>/，绝对路径写进 dir。名字为空、超长或含非法字符返回 400。

目录名由服务端拼，别自己建：名字规则改一次，自己拼的路径就对不上了。把这个 dir 写进从 AI 的提示词即可。

POST /rounds/{id}/close：关轮

接收：JSON，note（必填，本轮结论）、force（可选，默认 false）。

返回：更新后的轮次。还有 pending / running 的任务时返回 409，确认要关就带 force=true。

关闭后这一轮变成只读：新建任务、回写结果、发消息都返回 409，认领和改任务状态也拦。审核提案（recorded）不受限。

POST /rounds/{id}/reopen：启用回来

接收：无参数。

返回：更新后的轮次，status 回到 open，closed_at 清空。已经开着的轮返回 400。

关错了才用这个。结论（note）留着，下次关闭会被新写的覆盖；任务、结果、消息、runs/ 目录都不动。

DELETE /rounds/{id}：删轮

返回：{id, deleted, dir}。只能删一条数据都没挂的空轮；挂了任务、结果或消息返回 409，并报出各自条数。

有数据的轮只能关闭，不能删除——轮次编号会写进报告和 runs/ 目录名，删掉就是悬空引用。删轮不删目录，要清自己清。

界面

左侧栏顶部切换轮次，仪表盘、任务、结果、消息默认只显示选中那一轮，通过率、待审提案、[ISSUE] 都跟着这一轮走；资源和技能不受影响。

选中值记在地址栏 #/tasks?round=12 里，同时存一份到浏览器本地：链接里带了就以链接为准，没带就用上次看的，都没有就落到最新一轮。想直接看未归类用 ?round=none。

面板底部只有一个「新建轮次」。每一行右侧有个「⋯」，点开是这一轮自己的三个动作，规则和接口完全一样，人点界面、AI 调接口都行：

  • 启用：只有已归档的轮能点，作用等于 POST /rounds/{id}/reopen。
  • 关闭：必须写一句本轮结论。还有没跑完的任务时先提示，再点一次才强制关闭。
  • 删除：只对空轮可点，挂了数据就置灰。删掉的是轮次记录，runs/ 目录留着，要清自己清。
