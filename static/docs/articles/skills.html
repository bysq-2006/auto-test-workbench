技能

技能不进数据库。每次调用接口都会扫描 skills/*.py（以下划线开头的文件会跳过），只读文件内容，不会执行脚本。改技能就是在这个目录里增删或改脚本。

介绍写在文件内部，按下面的顺序读取：

  • 如果写了 SKILL = {"name": "...", "description": "..."}，优先用这里的名字和介绍。
  • 否则，技能名用文件名（不含 .py），介绍用文件开头的模块文档字符串。

作为参数引用技能

任务和结果都不存技能 id，只记 skill_path 文本。创建任务或回写结果时，skill 参数可以写下面任意一种，服务端都能解析到同一个脚本：

  • 相对路径：skills/echo_check.py
  • 带后缀的文件名：echo_check.py
  • 不带后缀的名字：echo_check
  • SKILL 里写的 name

解析不到就返回 400。脚本被删掉后，历史记录里的 skill_path 仍然保留，返回里补的 skill_name 会退回用路径里的文件名。

返回字段

真实名备注
name技能名，来自 SKILL 或文件名。
description介绍，来自 SKILL 或模块文档字符串。
path相对路径，比如 skills/echo_check.py。

后端 API

GET /skills：列出当前技能

接收：查询参数 q（可选，按名称、路径、介绍包含匹配）、limit（默认 10，最大 200）、page（默认 1）。

返回：对象 {items, total, page, limit}。items 里每项包含 name、description、path。没有写入接口。
